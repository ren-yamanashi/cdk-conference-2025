<section-title title="Construct の public プロパティを Construct 型にしない" />

<div v-click.hide="2" class="_bullet">

- Construct 型: `Construct` を継承しているクラス
  - `s3.Bucket`, `sqs.Queue` など

```ts{*|5}
import { Bucket } from "aws-cdk-lib/aws-s3";
import { Construct } from "constructs";

export class MyConstruct extends Construct {
  public readonly bucket: Bucket
  // ...
```

<div v-click="2" class="_bullet">

- Construct 型: `Construct` を継承しているクラス
  - `s3.Bucket`, `sqs.Queue` など

````md magic-move {at: 3}

```ts{5}
import { Bucket } from "aws-cdk-lib/aws-s3";

```

```ts{5|5}
import { IBucket } from "aws-cdk-lib/aws-s3";
import { Construct } from "constructs";

export class MyConstruct extends Construct {
  public readonly bucket: IBucket
  // ...
```

````

<br />

#### Construct 型にしてしまうと・・・

- 更新可能状態のリソースが公開され、意図しないリソースの更新が行われる危険性がある

<v-clicks at="3" depth="2">

- public プロパティの型は `IBucket` などの、<span v-mark="{at: 4, color: 'blue'}">読み取り専用リソースの型(Interface)</span> を指定する
  - 読み取り専用にする

</v-clicks>

Construct 型とは、Construct を継承しているクラス。と捉えていただけたらと思います。L1,L2,L3 Construct 全般と、自前で定義する Construct などが、こちらに当てはまるかなと思います。  

また、Construct の public プロパティとは、  
[click] こちらのような、Construct が外部に公開するプロパティのことです   
この例ですと、S3 Bucket の L2 Construct を 外部に公開しています。これにより、Stack や 他の Construct からも、MyConstruct の S3 Bucket が参照できるようになります。

[click] しかし、ここに Bucket などの Construct 型を指定してしまうと、更新可能な状態のリソースが外部に公開されてしまい、意図しない更新が行われる危険性があります。  

[click] そのため、IBucket のような「I なになに」とつく[click]読み取り専用リソースの型を指定することが推奨されます。  
そのような読み取り専用リソースを表す型を指定することで、外部からの書き込みを防ぎ、安全にリソースを公開することができます。
